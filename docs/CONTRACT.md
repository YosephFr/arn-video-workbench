# Workbench contract

Every bench in `benches/` follows the same shape so an agent can move between styles without relearning the plumbing. The shared tools in `core/` read and write the files described here.

## Layout of a bench

```
benches/<style>/
├── README.md          # what the style is for, the recipe, how to render, review checklist
├── engine/            # renderer (Node) for this style: kit, scenes helpers, render entry point
├── tools/             # style-specific helpers (optional)
├── brand/             # brand.json placeholders + where to drop your logo/fonts
├── samples/
│   └── <piece>/       # an EMPTY guiding sample: script.json (+ film.js / scene files) with placeholders
└── package.json       # if the engine needs Node dependencies
```

A *piece* is one video. It lives in its own folder (`samples/<piece>/` for the bundled examples, anywhere you like for your own) and accumulates generated files next to its inputs:

```
<piece>/
├── script.json        # input: lines, voices, music brief
├── film.js            # input (canvas/SVG benches): the animation, driven by timeline.json
├── voice/             # generated: takes per line (WAV + word timings), selection.json, proc/ (processed voice)
├── timeline.json      # generated: absolute timing of every line and word
├── events.json        # generated by the bench's events step: sound effects on the timeline
├── audio/             # generated: music.wav, sfx.wav, mix.wav, stems/
└── renders/           # generated: stills, preview.mp4, final.mp4
```

Generated files and folders are git-ignored, `events.json` included: declare effects where the action happens (in `film.js`, `scenes.html` or the bench's direction file) and let the bench's `events` step write the file. `core/bin/wb new <bench> <name>` copies a bench's sample without them.

## `brand.json`

```json
{
  "name": "Your Brand",
  "tagline": "One short line",
  "url": "yourbrand.example",
  "colors": { "background": "#F2F4F7", "surface": "#FFFFFF", "ink": "#14161A", "muted": "#626875", "accent": "#3B5BDB", "accent_ink": "#FFFFFF", "positive": "#2B7A4B", "negative": "#B23A3A" },
  "fonts": { "display": "Plus Jakarta Sans", "body": "Inter", "mono": "JetBrains Mono" },
  "logo": { "mark": "brand/logo-mark.svg", "wordmark": "brand/logo-wordmark.svg" },
  "radius": 28
}
```

Benches read the brand from `brand/brand.json` unless a piece overrides it with its own `brand.json`. Fonts come from Google Fonts (`core/bin/fetch-fonts.sh <Family> ...` downloads OFL TTFs into `assets/fonts/`, git-ignored). Logos are your own files; the bundled ones are neutral placeholders.

## `script.json`

```json
{
  "title": "Working title",
  "format": { "width": 1080, "height": 1920, "fps": 30 },
  "language": "en",
  "tail": 2.5,
  "voices": {
    "narrator": { "provider": "auto", "voice": "${WB_VOICE_NARRATOR}", "model": "eleven_multilingual_v2", "speed": 1.0 }
  },
  "lines": [
    { "id": "L01", "voice": "narrator", "text": "[warm] This is how *your* day adds up.", "start": 0.4 },
    { "id": "L02", "voice": "narrator", "text": "Eight services, half for you.", "after": "L01", "gap": 0.25 },
    { "id": "L03", "voice": "guest", "text": "Wait, what?", "with": "L02", "offset": 1.1, "effect": "phone", "caption": false }
  ],
  "keep_pauses": [ { "line": "L02", "after_word": 3, "max": 0.3 } ],
  "music": { "style": "pulse", "bpm": 96, "key": "A", "level": -22, "duck": -8, "sections": [ { "at": 0, "mood": "intro" }, { "at": "L02", "mood": "build" } ] },
  "mix": { "lufs": -14 }
}
```

- `text` markup: `[direction]` is a performance hint that is never spoken or captioned; `*emphasis*` is spoken normally and highlighted in captions. Write numbers as words when the captions must match the voice exactly.
- Placement: one of `start` (seconds), `after` + `gap` (after another line ends; default gap 0.2 s, negative overlaps) or `with` + `offset` (relative to another line's start; default 0). A line without any of them starts 0.25 s after the latest end of the lines before it (the first line at 0.3 s).
- Per line, optional: `effect` (`phone`, `radio`, `far`, `voice-note`), `caption: false` (hidden from captions), `gain_db` and `pan` (−1 to 1) in the mix, `takes`, `speed`, `tempo` and `seed` for the voice.
- `tail`: seconds after the last line ends (default 2.5). `format.fps` defaults to 30.
- `language`: the language of the lines. It is also the default `WB_LANGUAGE` for word timings from a local faster-whisper.
- `voices.*.provider`: `elevenlabs`, `openai`, `cosyvoice` (local), `say` (macOS), `silent`, or `auto` (first available of elevenlabs, openai, cosyvoice when the voice has a `profile` or `reference`, say, silent). Voice IDs and keys come from the environment, never from the file (`${VAR}` is expanded at run time). A voice may also set `tempo` (applied by `wb timeline`, pitch preserved); a CosyVoice voice sets `reference` + `reference_text` or `profile`, paths relative to the piece folder. See [`core/README.md`](../core/README.md).
- `music` (read by `wb music` and `wb mix`):

  | Key | Meaning |
  |---|---|
  | `provider` | `procedural` (default, needs nothing) or `elevenlabs` (needs `ELEVENLABS_API_KEY`) |
  | `style` | `pulse`, `tutorial` (default), `playful`, `ambient`, `news`, `tension` |
  | `bpm`, `key`, `scale` | tempo (default: the style's), root note (default `A`), `major` (default) or `minor` |
  | `sections` | `[{ "at": 0 \| "L03" \| "L03:word", "mood": "intro" }]`; moods `intro`, `build`, `main`, `lift`, `break`, `outro`. Without sections: intro, main, lift, outro |
  | `prompt` | extra style words for the `elevenlabs` provider |
  | `none` | `true`: no music |
  | `level` | loudness of the bed in LUFS before ducking (default −23.5) |
  | `duck` | dB the bed dips while a voice speaks (default −10) |

- `mix.lufs`: the integrated loudness `wb mix` normalises to (default −14; −15.5 for the studio bench), with true peak ≤ −1 dBTP checked after AAC encoding.

## `timeline.json` (generated by `core/bin/wb timeline`)

```json
{
  "duration": 21.4,
  "last_end": 18.9,
  "fps": 30,
  "lines": [
    {
      "id": "L01", "voice": "narrator", "text": "This is how your day adds up.",
      "start": 0.4, "end": 2.9, "audio": "voice/proc/L01.wav", "effect": null, "caption": true,
      "words": [ { "text": "This", "start": 0.4, "end": 0.58, "emphasis": false } ],
      "env": [0.0, 0.12, 0.64, 0.91]
    }
  ]
}
```

All times are absolute seconds from the start of the piece. `last_end` is where the last line ends and `duration` = `last_end` + `tail`. `audio` is the processed take of the line (pauses trimmed, tempo applied). `env` is the line's loudness envelope at 50 Hz (one value every 20 ms from the line's start, 0–1), used for mouth and level animation. Engines must derive every visual cue (camera moves, card reveals, highlights, captions) from these times instead of hard-coding seconds, so a re-recorded voice re-times the whole film.

## `events.json`

```json
[ { "t": 1.25, "name": "pop", "gain_db": -8, "pan": 0.0 }, { "at": "L02:Eight", "name": "whoosh" } ]
```

Written by the bench's `events` step (`render.mjs <piece> events`, or `studio plan` in two-character-studio) and git-ignored. `t` is absolute; `at` anchors to a word (`<line>:<word>`, the first word that starts with it) or a line (`<line>`). Optional: `gain_db` (default −12), `pan`, `rev` (reversed), `dur` (cut to seconds). Names map to the procedural library in `core/python/workbench/sfx.py` (`core/bin/wb sfx --list`) or to a WAV in `<piece>/audio/sfx/<name>.wav`.

## Rendering

Engines expose one entry point:

```
node benches/<style>/engine/render.mjs <piece> still 0.5,3,8   # frames for review
node benches/<style>/engine/render.mjs <piece> preview         # half-res MP4 with the mix
node benches/<style>/engine/render.mjs <piece> final           # full-res master with the mix
```

Stills land in the piece's `renders/`:

| Bench | Stills |
|---|---|
| `app-tutorial`, `calculation-explainer` (canvas), `story-highlights`, `cartoon-ads`, `particle-film`, `micro-ad-series` | PNG, `renders/stills/f_<t>.png` |
| `calculation-explainer` (HTML, through `core/node/frames.mjs`) | JPEG, `renders/still-<t>.jpg` |
| `progress-report-video` | PNG, `renders/stills/t<t>.png` |
| `two-character-studio` | PNG, `renders/stills/still-<t>.png` |
| `pdf-report` | page PNGs, `renders/qa/page-<n>.png` (the `pdf` mode) |

Rendering is deterministic: frame N shows exactly time N / fps. Browser-based engines use headless Chromium through Playwright and never open a visible window.

## Delivery checks (`core/bin/wb verify <video.mp4>`)

- Resolution (`--size`, default 1080x1920) and frame rate (`--fps`, default 30) as declared; duration within 0.25 s of `--expected` when given.
- Audio present; integrated loudness within ±1 LU of `--lufs` (default −14; −15.5 for the studio bench); true peak ≤ −1 dBTP.
- No black stretch of 0.3 s or more.
- No frozen stretch of 1.5 s or more, except one that starts inside the end-card hold (`--hold-end`, the last 2.5 s by default).
- File size at or under `--max-mb` (default 60).
- The first frames are not empty: a hook opens on content.

`--no-audio` skips the audio checks. The report is written to `<video>.verify.json` and the exit code is 1 when there are problems.
