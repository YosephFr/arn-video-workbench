# Open references

These open-source projects shaped parts of the workbench, or are worth studying next to it. Only links are listed here: none of their files are copied into this repository, with one exception, the Lucide icon path data in `benches/progress-report-video/engine/lib/icons.mjs`, which is embedded with its ISC licence notice. Follow the links and respect each license.

| Project | What to learn from it | License |
|---|---|---|
| [Product Film Skill](https://github.com/Rieranthony/product-film-skill) | Prompt templates and brand constraints for product films built from real UI components | MIT |
| [Launch Video Kit](https://github.com/borjaperfra/launch-video-kit) | Line-by-line narration, music analysis and extension, camera and subtitles for launch videos | MIT |
| [Anidoodle](https://github.com/alexgreensh/anidoodle) | Procedural illustration and consistent characters with Canvas/SVG | Apache-2.0 |
| [HyperFrames](https://github.com/heygen-com/hyperframes) | Contracts for agent-driven, frame-accurate HTML video composition | Apache-2.0 |
| [Claude Animation Base](https://github.com/JohnHeibel/ClaudeAnimationBase) | A guide, characters, scenes and render setup for code-driven animation | MIT |
| [Claude Animation Skill](https://github.com/buildwithhanif/claude-animation-skill) | Rigs, examples and sound for agent-made animation | MIT |
| [Three.js](https://threejs.org/) | The 3D engine behind `two-character-studio` | MIT |
| [@napi-rs/canvas](https://github.com/Brooooooklyn/canvas) | Skia for Node, used by the canvas benches | MIT |
| [Playwright](https://playwright.dev/) | Headless Chromium for HTML/SVG rendering and app captures | Apache-2.0 |
| [ReportLab](https://www.reportlab.com/opensource/) | PDF generation for `pdf-report` | BSD |
| [CosyVoice](https://github.com/QwenAudio/CosyVoice) | A local, open text-to-speech option; `core/bin/install-cosyvoice.sh` builds its GGUF runtime (see `core/README.md`) | Apache-2.0 |
| [Lucide](https://lucide.dev/) | The stroke icons of `progress-report-video` | ISC |
| [Google Fonts](https://fonts.google.com/) | Open (OFL) typefaces fetched by `core/bin/fetch-fonts.sh` | OFL / Apache |
